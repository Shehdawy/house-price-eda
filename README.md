# 🏠 House Price EDA Project

##  Project Overview
This project is part of the **IBM Machine Learning Professional Certificate (Coursera)**.  
The goal of this project is to perform **Exploratory Data Analysis (EDA)** on a house price dataset to understand the key factors that influence housing prices.

---

##  Dataset
- **Source:** Kaggle  
- **Type:** Housing data  
- **Description:** Contains features related to houses such as size, location, number of rooms, and other attributes that may affect price.

---

##  Objectives
- Understand the dataset structure and variables  
- Perform data cleaning and preprocessing  
- Explore patterns and relationships in the data  
- Generate meaningful insights  
- Formulate and test hypotheses

## 🔍 Exploratory Data Analysis (EDA)
The EDA process included:
- Understanding distributions of numerical features  
- Analyzing categorical variables  
- Identifying correlations between features  
- Detecting outliers  
- Visualizing data using plots and charts  

---

## 🧹 Data Cleaning & Feature Engineering
- Handling missing values  
- Removing or treating outliers  
- Encoding categorical variables  
- Creating new features where needed  

---

## 📈 Key Insights
- Property size has a strong relationship with price  
- Location plays a major role in price variation  
- Some features required cleaning due to missing or inconsistent values  

---

## 🧪 Hypothesis Testing
Example hypothesis:
- *H₀:* Feature X has no effect on house price  
- *H₁:* Feature X significantly affects house prices  

Statistical tests were applied to validate assumptions and support findings.
